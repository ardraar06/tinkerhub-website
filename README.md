# 🌟 TinkerHub NSSCE Community Website

A simple and responsive website for **TinkerHub NSS College of Engineering (NSSCE)**, inspired by the original [TinkerHub](https://tinkerhub.org) site.  
This project showcases the key sections of the TinkerHub NSSCE community.

---

## ✨ Features

✅ Community Announcements & Updates 📢  
✅ Events Section 🎭  
✅ Resource Sharing 📚  
✅ Forum/Chat for Discussions 💬  
✅ Student and Admin Login buttons (placeholder only) 🔐  
✅ Simple and Responsive Design 🎨

---

## 💻 Tech Stack

- **HTML5**
- **CSS3**

This is a lightweight, static site with no backend.

---

💬 Notes
The Student and Admin login buttons are placeholders; they currently show an alert message.
